# Product Roadmap

## Phase A — Verified baseline
- CI gates
- reproducible build
- dependency security gate
- Devnet/Testnet verification

## Phase B — Product readiness
- multi-wallet UX polish
- clear network indicators
- transaction and error states
- end-to-end UI flow testing
- deterministic demo flow

## Phase C — Competition readiness
- demo video
- architecture visuals
- pitch materials
- evidence package

## Phase D — Mainnet preflight
- independent review
- secrets review
- network configuration review
- disclosure review
- explicit human approval

Mainnet deployment is a separate decision and is not triggered automatically by CI.
