# JarSol Roadmap

## Phase A — Verified baseline
- CI gates
- reproducible build
- dependency security gate
- Devnet/Testnet verification

## Phase B — Product readiness
- polish wallet connection UX
- add explicit network indicators
- add transaction/error states
- improve demo flow
- document architecture and limitations

## Phase C — Competition readiness
- record deterministic demo
- prepare pitch and screenshots
- publish evidence links
- rehearse judge flow

## Phase D — Mainnet preflight
- independent code review
- independent RPC verification
- secrets review
- legal/disclosure review where applicable
- explicit human approval

Mainnet deployment is a separate decision, not an automatic roadmap step.
