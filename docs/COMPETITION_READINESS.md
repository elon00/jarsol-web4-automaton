# Competition Readiness

## Judge-ready flow
**Problem → Proof → Demo → Differentiation → Evidence**

### Submission checklist
- [ ] 2–3 minute deterministic demo video
- [ ] concise problem statement
- [ ] architecture diagram
- [ ] reproducible repository
- [ ] green CI evidence
- [ ] clear Devnet/Testnet/Mainnet labels
- [ ] known limitations disclosed
- [ ] roadmap separated from current functionality

## Claim policy
Never claim Mainnet deployment, regulatory approval, audited security, real liquidity, or live integrations without current evidence.
